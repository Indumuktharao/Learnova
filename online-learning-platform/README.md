# LearnSphere — Online Learning Platform

A responsive mini online learning platform built for the requested project.

## Included
### Beginner
- Homepage with featured courses
- Course listing
- Individual course details
- Enroll button

### Intermediate
- My Courses dashboard
- Percentage progress tracking
- Lesson completion checkboxes
- Responsive mobile/desktop design
- LocalStorage persistence

### Advanced demo
- Mock login/signup
- Completion certificate generation/print
- Spring Boot REST backend starter
- MySQL/JDBC-ready project structure

## Run the frontend
Open `frontend/index.html` directly in a browser, or use VS Code Live Server.

## Run the backend
Open a terminal inside `backend`:
```bash
mvn spring-boot:run
```

The frontend is intentionally usable without a database so it can be demonstrated easily.
